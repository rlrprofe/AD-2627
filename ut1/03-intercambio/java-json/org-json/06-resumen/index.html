    org.json — Resumen y referencia rápida¶

    1. ¿Qué hemos aprendido?¶

    org.json es una librería Java que permite crear, consultar y manipular estructuras JSON de forma explícita.

    Las tres clases que hemos utilizado principalmente son:

    JSONObject
JSONArray
JSONTokener

    Cada una tiene una función diferente:

    JSONObject
    │
    └── representa un objeto JSON
        { ... }


JSONArray
    │
    └── representa un array JSON
        [ ... ]


JSONTokener
    │
    └── ayuda a interpretar
        texto JSON

    A diferencia de Gson, con org.json trabajamos directamente con la estructura del documento JSON.

    Mapa general¶

    2. Los conceptos principales¶

    3. JSONObject¶

    JSONObject representa un objeto JSON.

    Por ejemplo:

    {
  "nombre": "Ana",
  "edad": 21,
  "activo": true
}

    En Java:

    JSONObject alumno =
        new JSONObject();

    Podemos añadir propiedades mediante:

    alumno.put(
    "nombre",
    "Ana"
);

alumno.put(
    "edad",
    21
);

alumno.put(
    "activo",
    true
);

    El resultado será equivalente a:

    {
  "nombre": "Ana",
  "edad": 21,
  "activo": true
}

    4. La idea clave de JSONObject¶

    Podemos imaginar un JSONObject como un conjunto de pares:

    CLAVE          VALOR

"nombre"  →    "Ana"

"edad"    →    21

"activo"  →    true

    Por tanto:

    JSONObject
     │
     ├── clave → valor
     ├── clave → valor
     └── clave → valor

    5. Crear propiedades con put()¶

    El método fundamental para construir un JSONObject es:

    put()

    Ejemplo:

    JSONObject alumno =
        new JSONObject();

alumno.put(
    "id",
    1
);

alumno.put(
    "nombre",
    "Ana"
);

alumno.put(
    "nota",
    8.5
);

    Podemos resumir:

    JSONObject
     │
     │ put(clave, valor)
     ▼
 propiedad JSON

    6. Recuperar valores¶

    Una vez construido el objeto podemos recuperar sus valores.

    Por ejemplo:

    String nombre =
        alumno.getString(
            "nombre"
        );

    También disponemos de métodos como:

    getInt()
getDouble()
getBoolean()
getJSONObject()
getJSONArray()

    La elección depende del tipo de dato que esperamos encontrar.

    7. Métodos get...¶

    Los métodos get...() esperan que la propiedad exista y que podamos obtenerla con el tipo correspondiente.

    Ejemplos:

    String nombre =
        alumno.getString(
            "nombre"
        );

    int id =
        alumno.getInt(
            "id"
        );

    double nota =
        alumno.getDouble(
            "nota"
        );

    Podemos asociar:

    getString()     → String

getInt()        → int

getDouble()     → double

getBoolean()    → boolean

getJSONObject() → JSONObject

getJSONArray()  → JSONArray

    8. Métodos opt...¶

    Cuando una propiedad puede no existir podemos utilizar los métodos:

    opt...

    Por ejemplo:

    String telefono =
        alumno.optString(
            "telefono",
            "No disponible"
        );

    Si existe:

    "telefono": "600123123"

    obtendremos:

    600123123

    Si no existe, podremos obtener el valor indicado:

    No disponible

    9. get... frente a opt...¶

    Una de las diferencias importantes que debemos recordar es:

    get...
   │
   └── esperamos que el dato exista


opt...
   │
   └── permitimos tratar
       datos opcionales

    Ejemplo:

    alumno.getString(
    "nombre"
);

    frente a:

    alumno.optString(
    "telefono",
    "No disponible"
);

    Tip

    Los métodos opt...() son especialmente útiles cuando trabajamos con información que puede ser opcional.

    10. Comprobar si existe una propiedad¶

    Podemos utilizar:

    has()

    Por ejemplo:

    if (alumno.has("telefono")) {

    System.out.println(
        alumno.getString(
            "telefono"
        )
    );
}

    Conceptualmente:

    JSONObject
     │
     │ has("telefono")
     ▼
¿existe la propiedad?

    11. Eliminar una propiedad¶

    Podemos eliminar una propiedad mediante:

    remove()

    Por ejemplo:

    alumno.remove(
    "telefono"
);

    Después la propiedad dejará de formar parte del objeto.

    12. Modificar una propiedad¶

    Podemos volver a utilizar:

    put()

    sobre una clave existente.

    Por ejemplo:

    alumno.put(
    "nota",
    8.5
);

    y posteriormente:

    alumno.put(
    "nota",
    9.2
);

    El valor asociado a:

    nota

    quedará actualizado.

    13. Valores null¶

    JSON permite representar la ausencia explícita de un valor mediante:

    null

    En org.json podemos encontrarnos con:

    JSONObject.NULL

    Es importante distinguir conceptualmente:

    propiedad inexistente

    de:

    propiedad existente
con valor null

    Por ejemplo:

    {
  "telefono": null
}

    no es exactamente lo mismo que:

    {
}

    14. Objetos anidados¶

    Un objeto JSON puede contener otro objeto.

    Por ejemplo:

    {
  "id": 1,
  "nombre": "Ana",
  "direccion": {
    "ciudad": "Alcalá de Henares",
    "codigoPostal": "28801"
  }
}

    Podemos construirlo mediante:

    JSONObject direccion =
        new JSONObject();

direccion.put(
    "ciudad",
    "Alcalá de Henares"
);

direccion.put(
    "codigoPostal",
    "28801"
);

JSONObject alumno =
        new JSONObject();

alumno.put(
    "id",
    1
);

alumno.put(
    "nombre",
    "Ana"
);

alumno.put(
    "direccion",
    direccion
);

    15. Recuperar un objeto anidado¶

    Podemos obtener:

    JSONObject direccion =
        alumno.getJSONObject(
            "direccion"
        );

    y después:

    String ciudad =
        direccion.getString(
            "ciudad"
        );

    El recorrido es:

    alumno
   │
   │ getJSONObject("direccion")
   ▼
direccion
   │
   │ getString("ciudad")
   ▼
"Alcalá de Henares"

    16. JSONArray¶

    JSONArray representa un array JSON.

    Por ejemplo:

    [
  "Java",
  "Python",
  "Kotlin"
]

    En Java podemos crear:

    JSONArray lenguajes =
        new JSONArray();

    y añadir elementos mediante:

    lenguajes.put(
    "Java"
);

lenguajes.put(
    "Python"
);

lenguajes.put(
    "Kotlin"
);

    17. put() en JSONArray¶

    También utilizamos:

    put()

    para añadir elementos a un array.

    Pero ahora no proporcionamos una clave:

    array.put(valor);

    Por ejemplo:

    lenguajes.put(
    "Java"
);

    Los elementos quedan almacenados mediante posiciones:

    JSONArray
   │
   ├── [0] "Java"
   ├── [1] "Python"
   └── [2] "Kotlin"

    18. length()¶

    Podemos conocer el número de elementos mediante:

    length()

    Por ejemplo:

    int cantidad =
        lenguajes.length();

    Si tenemos:

    [
  "Java",
  "Python",
  "Kotlin"
]

    obtendremos:

    3

    19. Acceder por posición¶

    Podemos recuperar los elementos indicando su índice.

    Por ejemplo:

    String lenguaje =
        lenguajes.getString(0);

    obtendremos:

    Java

    Recordemos que los índices comienzan en:

    0

    20. Recorrer un JSONArray¶

    Una forma habitual es utilizar:

    for

    junto con:

    length()

    Por ejemplo:

    for (int i = 0;
        i < lenguajes.length();
        i++) {

    System.out.println(
        lenguajes.getString(i)
    );
}

    Esquema:

    i = 0 → Java

i = 1 → Python

i = 2 → Kotlin

    21. JSONArray de objetos¶

    Un JSONArray puede contener objetos.

    Por ejemplo:

    [
  {
    "id": 1,
    "nombre": "Ana"
  },
  {
    "id": 2,
    "nombre": "Luis"
  }
]

    Conceptualmente:

    JSONArray
   │
   ├── JSONObject
   │      ├── id
   │      └── nombre
   │
   └── JSONObject
          ├── id
          └── nombre

    22. Recorrer un array de objetos¶

    Podemos hacer:

    for (int i = 0;
        i < alumnos.length();
        i++) {

    JSONObject alumno =
            alumnos.getJSONObject(i);

    System.out.println(
        alumno.getString(
            "nombre"
        )
    );
}

    El proceso es:

    JSONArray
    │
    │ getJSONObject(i)
    ▼
JSONObject
    │
    │ getString("nombre")
    ▼
nombre

    23. JSONObject con JSONArray¶

    También podemos combinar ambas estructuras:

    {
  "nombre": "Ana",
  "modulos": [
    "Acceso a Datos",
    "Programación Multimedia",
    "Sistemas de Gestión Empresarial"
  ]
}

    En Java:

    JSONArray modulos =
        new JSONArray();

modulos.put(
    "Acceso a Datos"
);

modulos.put(
    "Programación Multimedia"
);

modulos.put(
    "Sistemas de Gestión Empresarial"
);

JSONObject alumno =
        new JSONObject();

alumno.put(
    "nombre",
    "Ana"
);

alumno.put(
    "modulos",
    modulos
);

    24. Recuperar un JSONArray anidado¶

    Podemos hacer:

    JSONArray modulos =
        alumno.getJSONArray(
            "modulos"
        );

    y después recorrerlo:

    for (int i = 0;
        i < modulos.length();
        i++) {

    System.out.println(
        modulos.getString(i)
    );
}

    25. Recorrer las claves de JSONObject¶

    También podemos recorrer las propiedades de un objeto.

    Por ejemplo:

    for (String clave :
        alumno.keySet()) {

    System.out.println(
        clave
        + " = "
        + alumno.get(clave)
    );
}

    Si tenemos:

    {
  "id": 1,
  "nombre": "Ana",
  "nota": 8.5
}

    podremos acceder a sus diferentes claves y valores.

    26. Guardar JSON en un fichero¶

    Una estructura JSON que está en memoria desaparece cuando termina el programa.

    Para conservarla debemos guardarla.

    Por ejemplo:

    JSONObject
     │
     │ toString()
     ▼
texto JSON
     │
     ▼
FileWriter
     │
     ▼
 fichero

    27. toString()¶

    Podemos obtener la representación JSON mediante:

    objeto.toString();

    Por ejemplo:

    String json =
        alumno.toString();

    28. JSON con formato¶

    También podemos utilizar:

    toString(4)

    Por ejemplo:

    String json =
        alumno.toString(4);

    El número:

    4

    indica la indentación utilizada para presentar el JSON.

    Así obtenemos un documento más legible.

    29. FileWriter¶

    Podemos escribir:

    try (FileWriter writer =
        new FileWriter(
            "data/persona.json"
        )) {

    writer.write(
        persona.toString(4)
    );
}

    El recorrido es:

    JSONObject
     │
     │ toString(4)
     ▼
String JSON
     │
     │ write()
     ▼
FileWriter
     │
     ▼
persona.json

    30. Leer JSON desde un fichero¶

    Para recuperar un JSON almacenado podemos utilizar:

    FileReader
     +
JSONTokener

    El recorrido será:

    fichero
   │
   ▼
FileReader
   │
   ▼
JSONTokener
   │
   ▼
JSONObject / JSONArray

    31. JSONTokener¶

    JSONTokener ayuda a interpretar una secuencia de caracteres como contenido JSON.

    Por ejemplo:

    try (FileReader reader =
        new FileReader(
            "data/persona.json"
        )) {

    JSONTokener tokener =
            new JSONTokener(
                reader
            );

    JSONObject persona =
            new JSONObject(
                tokener
            );
}

    32. ¿Qué papel tiene cada clase?¶

    FileReader
    │
    └── lee caracteres
        desde el fichero


JSONTokener
    │
    └── interpreta el flujo
        como contenido JSON


JSONObject
    │
    └── representa el objeto
        JSON resultante

    33. nextValue()¶

    Cuando no sabemos de antemano si la raíz del documento es un objeto o un array, podemos utilizar:

    tokener.nextValue();

    Por ejemplo:

    Object valor =
        tokener.nextValue();

    Después podemos comprobar qué estructura hemos recibido.

    Con Java 21 podemos utilizar:

    if (valor instanceof JSONObject objeto) {

    System.out.println(
        "Es un objeto JSON"
    );

} else if (
        valor instanceof JSONArray array) {

    System.out.println(
        "Es un array JSON"
    );
}

    34. JSONObject o JSONArray en la raíz¶

    Un documento puede comenzar por:

    {

    En ese caso tenemos:

    JSONObject

    O puede comenzar por:

    [

    En ese caso tenemos:

    JSONArray

    Podemos resumir:

    { ... }  → JSONObject

[ ... ]  → JSONArray

    35. El ciclo completo¶

    Ya podemos realizar todo el proceso:

                        CREAR

datos Java
    │
    ▼

    │
    │ put()
    ▼
estructura JSON
    │
    │ toString(4)
    ▼
FileWriter
    │
    ▼
fichero JSON
    │
    │ FileReader
    ▼
JSONTokener
    │
    ▼
JSONObject / JSONArray
    │
    │ get...() / opt...()
    ▼
datos

    36. Chuleta de JSONObject¶

    Operación Método

    Obtener booleano getBoolean(clave)
    Obtener objeto getJSONObject(clave)
    Obtener array getJSONArray(clave)

    Entero opcional optInt(clave)

    Comprobar propiedad has(clave)
    Eliminar propiedad remove(clave)

    37. Chuleta de JSONArray¶

    Operación Método

    Obtener texto getString(indice)
    Obtener entero getInt(indice)
    Obtener decimal getDouble(indice)
    Obtener objeto getJSONObject(indice)
    Obtener array getJSONArray(indice)
    Generar JSON toString()
    JSON indentado toString(4)

    38. Chuleta de lectura de ficheros¶

    Para un objeto:

    try (FileReader reader =
        new FileReader(
            "data/persona.json"
        )) {

    JSONTokener tokener =
            new JSONTokener(
                reader
            );

    JSONObject persona =
            new JSONObject(
                tokener
            );
}

    Para una raíz desconocida:

    try (FileReader reader =
        new FileReader(
            "data/datos.json"
        )) {

    JSONTokener tokener =
            new JSONTokener(
                reader
            );

    Object valor =
            tokener.nextValue();
}
