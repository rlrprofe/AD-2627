# Acceso a Datos · 2º DAM

Materiales del módulo **Acceso a Datos**.

## Unidades de trabajo

### UT1 · Ficheros y formatos de intercambio de datos

En esta unidad se trabaja con:

- ficheros y directorios;
- acceso secuencial y aleatorio;
- flujos de bytes y caracteres;
- serialización y deserialización de objetos;
- JSON y XML;
- analizadores DOM, SAX y JAXB;
- consultas XPath;
- conversión entre XML y JSON.
