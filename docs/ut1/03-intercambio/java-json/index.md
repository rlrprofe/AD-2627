# JSON con Java

!!! info "Proyectos Java 21 actualizados"
    Se han actualizado los proyectos Maven de **org.json**, **Gson** y **Jackson**. Entra en la página inicial de cada librería para consultar el orden de estudio, los paquetes y el enlace al ZIP revisado. Los fragmentos aislados de los apuntes son explicaciones conceptuales; la referencia para ejecutar es el código del proyecto descargable.

En este bloque aprenderemos a trabajar con **JSON desde Java** utilizando diferentes librerías.

### Librerías

#### 1. org.json

Creación, lectura y manipulación de documentos JSON utilizando las clases `JSONObject` y `JSONArray`.

#### 2. Gson

Conversión entre objetos Java y JSON utilizando la librería Gson de Google.

#### 3. Jackson

Serialización y deserialización de objetos Java utilizando Jackson y `ObjectMapper`.
