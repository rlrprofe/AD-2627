# 4. Analizadores XML con Java

Un analizador XML permite interpretar la estructura de un documento para acceder a sus elementos, atributos y contenido.

## Enfoques principales

| Tecnología | Modelo | Adecuado para |
|---|---|---|
| **DOM** | Árbol completo en memoria | Leer, modificar y guardar XML pequeños/medianos |
| **SAX** | Eventos durante lectura secuencial | XML grandes y procesamiento de lectura |
| **JAXB / Jakarta XML Binding** | XML ↔ objetos Java | Trabajar con un modelo de clases |
