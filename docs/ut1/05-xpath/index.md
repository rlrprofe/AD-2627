# 5. Consultas XML con XPath

XPath es un lenguaje de expresiones que permite seleccionar información dentro de un documento XML sin recorrer manualmente todo el árbol DOM.

## Ejemplo

```xpath
//producto[precio > 50]/nombre/text()
```

## Qué estudiaremos

- rutas absolutas y relativas;
- selectores;
- atributos;
- predicados y filtros;
- funciones;
- tipos de resultado;
- evaluación desde Java.
