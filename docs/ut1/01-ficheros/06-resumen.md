# Resumen · Ficheros

## Elección rápida

| Quiero... | Utilizo... |
|---|---|
| Gestionar un fichero/directorio | `File` |
| Leer/escribir texto | `Reader` / `Writer` |
| Leer líneas | `BufferedReader` |
| Escribir texto cómodamente | `PrintWriter` |
| Trabajar con binarios | `InputStream` / `OutputStream` |
| Guardar tipos primitivos | `DataInputStream` / `DataOutputStream` |
| Saltar a posiciones concretas | `RandomAccessFile` |
| Cerrar automáticamente recursos | `try-with-resources` |
