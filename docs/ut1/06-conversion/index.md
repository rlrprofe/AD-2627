# 6. Conversión XML ↔ JSON

XML y JSON representan información estructurada de formas diferentes. En muchas aplicaciones necesitamos transformar datos de un formato a otro.

## Dos direcciones

```text
XML  ─────────► JSON
JSON ─────────► XML
```

## Dos enfoques

- **Conversión manual:** controlamos explícitamente cómo se transforma cada nodo, atributo, objeto o array.
- **Conversión automática:** utilizamos librerías y modelos de datos para reducir el código de transformación.
